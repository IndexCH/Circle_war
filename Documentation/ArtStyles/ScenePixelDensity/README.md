# 第一场景统一像素密度

当前密度已微调为 **54 逻辑像素/世界单位**，当前 1080p 下约 **2×2 屏幕像素/颗粒**，以提高箱子等小物件清晰度。最新截图和验证见 `Fine54/`。以下保留初版 36 密度的实现与验证记录。

所有春季像素景物使用同一个世界坐标像素网格：每世界单位 36 个逻辑像素。
当前相机半高为 5，在 1920 × 1080 画面中，每个逻辑像素约占 3 × 3 屏幕像素。

例如宽 8.6 世界单位的圆环使用约 310 个逻辑像素；宽 0.81 世界单位的箱子使用约 29 个逻辑像素。物体越大，占用的像素数量越多，每个像素的世界尺寸一致。

## 实现

- `Assets/Resources/ArtStyles/ScenePixelDensity.mat` 中的 `Scene pixels per world unit` 是统一密度参数。
- `ScenePixelDensity` 保存每个 SpriteRenderer 原材质；在像素风场景中使用共享材质，切回原图时恢复原材质。无需逐帧 CPU 扫描或逐物件设定像素倍率。
- `ScenePixelGrid.hlsl` 在片元阶段将 UV 对齐到世界坐标网格；贴图画布、导入 PPU、物体缩放与旋转均参与实际世界位置计算。大物件获得更多逻辑像素，小物件相应减少。
- 渲染 shader 基于项目现有 Unity 6000.4 / URP 的 Sprite-Lit-Default，沿用 2D 光照、法线和回退 pass，并对纹理和 2D 光照使用相同网格。
- 像素场景 Sprite 使用 Full Rect 网格，以便透明轮廓完全由统一像素采样控制。Point 采样、无 mipmap、原 PPU 和原 Sprite 引用保持。
- 处理春季像素圆环、背景、环境物件，以及叠在圆环上的细装饰线。人物动画、NPC、怪物、HUD 和玩法不在本轮修改范围内。

圆环原纹理中已经画大的块状纹理无法靠提高 PPU 恢复细节，因此另用内置 image_gen 细化原圆环表面，再应用与其他物件一致的网格。保持原轮廓、窄边带、冷灰白配色，脚本只执行此前用户已允许的绿幕透明背景清理，未用脚本重画纹理。

原始圆环在本轮工作目录 `scene-density/before/Assets/ArtStyles/SpringPixel/` 中备份；更早的原版美术始终保留在项目 Resources 下。

生成提示词见 `RING-PROMPT.md`。运行验证与实机截图见同目录中的检查报告及 PNG。

## 验证结果

11 项运行检查通过：18 种素材及圆环叠加层共用网格，原材质切换恢复，玩家位置/路径/进度与 HUD 保持，箱子放大到 150% 以及场景旋转 23° 后维持同一世界像素尺寸。

读取截图中的 3×3 像素格验证实际输出：地图内部选区的格内颜色一致率为 99.96%，修改前为 14.79%；箱子放大后为 99.95%。圆环条带为 95.41%，剩余非一致格位于轮廓裁切、遮罩交界和非场景角色叠加等处。具体采样区域与容差由 `check_grid.py` 记录，数值见 `pixel-grid-measurement.json`，不等同于整屏 100% 像素化。

Unity Console 最终 0 条错误、0 条警告；渲染后的 shader 变体无编译错误。未做独立 Player 构建。
