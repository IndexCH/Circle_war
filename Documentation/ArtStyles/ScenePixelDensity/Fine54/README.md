# 统一场景颗粒微调：54 像素/世界单位

共享场景材质的 `_PixelsPerUnit` 由 36 调到 54，shader 默认值同步。当前相机与 1080p 画面下，颗粒由 3×3 减小到 2×2 屏幕像素。

箱子约从 29×38 增加到 44×57 个逻辑像素，单件可显示的像素数量约增加 125%，保留更多轮廓、锁扣和金属边框细节。所有景物仍使用同一世界坐标网格。

实际运行确认共享密度 54、屏幕颗粒 2、当前可见的 7 个场景渲染器使用同一材质。已检查游戏截图中的箱子与其他景物，Unity Console 无错误、无警告。此次仅调整密度参数，未改变布局、图片或玩法。

`scene-fine.png` 为更新后的运行截图，`checks.txt` 为运行参数记录。此前 36 密度的完整验证保留在上级目录。
