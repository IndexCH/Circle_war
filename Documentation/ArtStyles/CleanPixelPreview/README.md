# 简洁像素预览

场景：`Assets/Scenes/SpringPixelPreview.unity`。

- 清除了旧的 `Pixel Polish Validation` 临时怪物展示组。怪物资源及正常生成逻辑仍在。
- 圆圈地面的 `_ReferencePixelSize` 为 **1**；在 1920×1080、正交相机尺寸 5 下验证为 1 屏幕像素。
- 地面使用独立 `GroundPixelDensity` 着色器。只对颜色进行小范围取样和色阶简化，保留原图透明轮廓。最终参数：细节简化 **0.45**、取样半径 **1**、色阶 **16**。背景、道具、怪物材质不受这项简化影响。
- 正文、信息流和资源数值采用 Fusion Pixel 10px 字体的整数 2 倍尺寸（20px）；紧凑标签采用 8px 字体的 2 倍尺寸（16px）。原 UI 框、配色、位置保留。选项内部文字区域高度从 48 调至 50，仍位于原按钮内部。
- 正文行距采用 21px，足以分隔 20px 点阵字形。708 个项目中文字符无缺字，178 条对话和选项无溢出。
- 原白色 UI 圆环继续隐藏；FEEL 示例音效继续解除绑定。
