# SpringPixelPreview

> Updated presentation: body text now uses native 16-dot GNU Unifont, ground pixels are 1.3, and monsters use pixel sampling. See `../PixelPolish/README.md` for the latest setup and verification. The screenshots and typography measurements in this folder document the first preview version.

Open `Assets/Scenes/SpringPixelPreview.unity` and press Play. The independent scene combines the latest Spring environment (54 world pixels per unit, approximately 2 screen pixels at 1920×1080), the original HUD artwork rendered on a 2-pixel grid, and Chinese pixel typography.

The original SampleScene file is preserved. The new scene was saved from the complete current editor scene, including its previously unsaved state. Environment props are generated by the existing CircleMapView at runtime, as in the source scene. F6 still switches environment art and frame sampling; this preview's fonts stay pixel fonts.

## UI

Original Image sprites, positions, dimensions, tints, and Button SpriteSwap transitions are unchanged. Portraits and character artwork retain their existing rendering. Only the text boxes receive minimal font padding: headings accommodate the font ascent/descent, and choice labels use the existing button's interior to allow two lines. Dialogue and feed line spacing is set for the new font metrics.

`PixelHudTypography` is attached only to the preview Canvas. Its three font references also style generated resource, insufficient-resource, damage, and fallback dialogue labels. Other scenes without this component retain their original typography.

## Font

Fusion Pixel Font / 缝合像素字体, release **2026.09.01**, proportional Simplified Chinese (`zh_hans`).

- Project: https://github.com/TakWolf/fusion-pixel-font
- Release: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01
- Font license: SIL Open Font License 1.1; original fonts are included unmodified.
- Assets: `Assets/ArtStyles/Fonts/FusionPixel/`; `OFL.txt` and the release packages' upstream license files are included beside the fonts.
- 8px face at 16px for body text; 10px face at 20px for medium labels; 12px face at 24px for headings. Resource gains use 10px at 30px and damage uses 12px at 36px.
- Unity dynamic font import includes font data, uses HintedRaster, and has no fallback font references. Texture filtering is Point. Automatic text fitting and synthetic bold are disabled to preserve the pixel grid. Popups keep their existing outlines and color coding.

## Validation

The screenshots are actual 1920×1080 Game View captures. The UI inspection confirms all 19 authored labels use Fusion Pixel Font. All 708 distinct Chinese characters found in first-party game data and scripts are available in all three font faces. Existing event choice callbacks, generated resource messages, and player damage labels were exercised in Play Mode. Original UI Image layout snapshots match exactly.

All 178 authored dialogue/event body and choice strings fit their existing UI areas. The longest body renders all 56 characters in six lines, with a preferred height of 114px inside the 140px text area. Final Play Mode Console: 0 errors, 0 warnings. `git diff --check` passes.

Temporary capture scripts initially assumed a lazily-created feedback component was already present and produced two probe-only NullReferenceExceptions; the corrected capture initializes it through the HUD's existing public API and completes. These scripts are outside Assets and are not included in the game.

No player build was requested or produced. No commit or push was performed.
