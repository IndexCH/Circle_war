# GNU Unifont 17.0.04

Official, unmodified OpenType font from Unifoundry. Used as the native 16-dot body font in `SpringPixelPreview.unity`; Chinese glyphs have a full 16×16 grid instead of enlarged 8-dot approximations.

Project: https://www.unifoundry.com/unifont/index.html

Download: https://unifoundry.com/pub/unifont/unifont-17.0.04/font-builds/unifont-17.0.04.otf

Font license: SIL Open Font License 1.1, also offered under GNU GPL 2+ with the font embedding exception. See the original `Unifont-OFL.txt` and `Unifont-LICENSE.txt` files beside the font. The OTF has not been modified or subsetted.

Unity import: Dynamic, included font data, HintedRaster, 16px. PixelHudTypography keeps point filtering and uses a 20px baseline advance for body text. Larger headings and popups still use the previously imported Fusion Pixel optical sizes.
