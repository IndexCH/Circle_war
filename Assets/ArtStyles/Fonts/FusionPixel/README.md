# 缝合像素字体 / Fusion Pixel Font

Unmodified official TrueType release 2026.09.01, proportional Simplified Chinese variants at 8px, 10px and 12px.

Project: https://github.com/TakWolf/fusion-pixel-font

Release: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01

License: SIL Open Font License 1.1. See OFL.txt and Licenses-8px / Licenses-10px / Licenses-12px for the copyright notices and upstream font licenses shipped in each official package. The font files have not been altered or subsetted.

Used in Assets/Scenes/SpringPixelPreview.unity via PixelHudTypography for headings (12px face at 24px), resource gains (10px at 30px), and damage messages (12px at 36px). Body text now uses GNU Unifont's full native 16-dot Chinese glyphs for readability. The 8px face is retained for the original comparison and fallback configuration. Font data is included in Unity builds so Chinese rendering does not depend on an operating-system font.
