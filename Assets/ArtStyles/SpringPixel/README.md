# 盐尘平原 · 像素场景版本

第一场景（春季 Spring）的场景美术重绘。配色以灰白盐壳、冷灰岩土、灰褐枯木和灰绿金属为主，紫晶、蓝晶和灰粉菌菇作为点缀。

## 使用

1. 打开 `Assets/Scenes/SampleScene.unity`，进入 Play；春季默认使用像素版。
2. 游戏窗口获得键盘焦点后按 **F6**，在同一位置切换原版与像素版。
3. 固定使用原版：选择 `Assets/Resources/ArtStyles/SpringPixelArtStyle.asset`，取消 `Enabled By Default`。
4. 退出 Play 后再进入，会重新使用该资源的默认选项。

原始图片、季节配置及道路定义均保留。映射只应用于 spring。NPC、玩家、怪物和战斗反馈沿用现有资源。UI 保留原图、布局、配色与文字，春季像素模式仅应用原图像素采样材质；F6 同步对比原 UI 与像素 UI。编辑模式下场景保留原图，运行时应用映射。

## 资源

18 张 PNG：背景、圆环和 16 张独立物件图片；断缆图片用于两处原引用，共覆盖 17 个环境物件引用。资源均在本目录。
Sprite 使用 Point 采样、无 mipmap、无纹理压缩。导入时保留生成图尺寸，运行时按原 Sprite 的世界尺寸校正缩放及底部对齐。
NPC 动画若复用主场景渲染器，会跳过该渲染器的像素缩放。

美术与配色修正使用内置 image_gen；透明背景清理及空白裁切采用用户明确允许的脚本。
完整最终提示词见 [PROMPTS.md](PROMPTS.md)。

## 背景与原 UI 像素化修正

圆环图片尺寸补偿不再缩小其子物体的遮罩参照，春季背景等比居中铺满圆环内部。原 UI 像素化采用 2 屏幕像素采样，未重画 UI，未改变原面板布局与配色。最新截图与 14 项运行检查见 `Documentation/ArtStyles/OriginalHudPixel/`。

## 场景像素密度统一

箱子、树、电线杆、背景和圆环等 18 种像素环境图片统一按每世界单位 54 个逻辑像素采样。当前 1080p 相机下每颗约 2×2 屏幕像素，物体越大分配越多逻辑像素；缩放或旋转不会单独改变颗粒尺寸。圆环表面另行细化，叠加装饰线也使用相同网格。UI 保持上一轮的原图像素化方案。

最新场景截图、各物件密度表与 11 项运行检查见 `Documentation/ArtStyles/ScenePixelDensity/`。

## 像素清晰度微调

统一密度由 36 调高至 54，每颗在当前 1080p 下从 3×3 减小为 2×2 屏幕像素。箱子约从 29×38 增加到 44×57 个逻辑像素，保留更多锁扣、边框等细节。最新截图见 `Documentation/ArtStyles/ScenePixelDensity/Fine54/`。
