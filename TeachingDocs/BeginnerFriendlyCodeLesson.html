Unity 新手教学友好版代码讲解

主题：用 Game 视图做圆形地图窗口，而不是用复杂 UI RecyclerView。

本次重构前的问题

  • 旧版本使用 UGUI、RecyclerView、ViewHolder、Adapter 等概念，新手需要同时理解很多抽象。
  • 圆圈、人物和背景都放在 Canvas 里，和普通 2D 游戏物体的学习路径不一致。
  • 代码里有泛型、继承、接口、事件系统等内容，老师很难按 Unity 基础顺序讲清楚。
  • 报错时堆栈会进入第三方包，新手不知道应该先看哪一段自己的代码。

本次重构后的代码阅读顺序

  1. 先看 CircleMapRecyclerViewDemo.Start：游戏开始时调用 Build。
  2. 再看 Build：它按顺序创建背景、圆圈、12 个可见段位、人物。
  3. 然后看 CreateRoadData：这里创建 30 段真实道路数据。
  4. 接着看 RefreshVisibleSegments：这里把 30 段数据投影到 12 个圆圈位置。
  5. 最后看 StepForward 和 StepBackward：它们控制前进、后退和进入大地图。

课堂上可以先把“数据层”和“表现层”画成两条线：数据层有 30 段，表现层只有 12 个 SpriteRenderer。

每个脚本的职责说明

CircleMapRecyclerViewDemo

负责整个圆形地图：加载资源、生成道路数据、创建场景物体、读取键盘输入、控制前进后退。

CircleMapSegment

只负责一个可见段位：显示图片、颜色、名字，并在玩家位置对应的格子上放大。

核心变量解释

  • roadDataList：真实道路数据列表，暂时有 30 段。
  • visibleSegmentList：圆圈上实际创建出来的 12 个显示物体。
  • currentRoadSegmentIndex：玩家当前走到第几段道路。
  • circleRotatingRoot：圆圈和段位的父物体，旋转它就能让整个圆圈转起来。
  • PlayerVisibleSlotIndex：人物固定在 6 点钟方位，对应圆圈底部的可见槽位。
  • FrontEntryVisibleSlotIndex：12 点钟附近的前方入口，新道路会从这里出现。

核心方法解释

Build：按教学顺序搭场景

public void Build()
{
    ClearOldMapObjects();
    CreateIconSprites();
    CreateRoadData();
    CreateBackground();
    CreateCircleRoot();
    CreateRing();
    CreateVisibleSegments();
    CreatePlayer();
}

这段代码像搭积木一样，从背景到人物一步一步创建。老师可以让学生在每个方法里打断点，看场景里多了什么物体。

RefreshVisibleSegments：数据层和表现层分开

int roadSegmentIndex = GetRoadDataIndexForVisibleSlot(visibleSlotIndex);

if (roadSegmentIndex < 0)
{
    visibleSegment.ShowEmptyLand(emptySegmentSprite, "起点后方空地");
}
else
{
    CircleRoadSegmentData roadData = roadDataList[roadSegmentIndex];
    visibleSegment.ShowRoadData(...);
}

这里的重点是：12 个可见物体不会增加，只是每次把不同的道路数据交给它们显示。

StepForward：前进一段

int nextRoadSegmentIndex = currentRoadSegmentIndex + 1;

if (nextRoadSegmentIndex >= roadDataList.Count)
{
    EnterBigMap();
    return;
}

MoveToRoadSegment(nextRoadSegmentIndex, true);

当玩家超过第 30 段时，不再继续生成小圆圈内容，而是切换到大地图占位画面。

Unity 生命周期讲解

  • Start 游戏物体启用后调用一次。这里用来搭建演示场景。
  • Update 每一帧调用一次。这里不写复杂逻辑，只调用读取输入和转动圆圈。
  • OnDestroy 物体销毁时调用。这里释放运行时生成的 Sprite 和 Texture。

本课暂时没有使用 OnTriggerEnter。如果以后给段位加碰撞器，玩家进入某个区域时，就可以用它触发采集、战斗或事件。

新手容易犯错的地方

  • 把 UI 的像素大小直接拿来当世界单位。Game 视图里应该用米一样的世界单位。
  • 忘记设置 SpriteRenderer.sortingOrder，导致人物被背景挡住。
  • 把 30 段数据都创建成 30 个物体。这里为了讲“窗口”，只创建 12 个显示物体。
  • 起点还允许后退。代码里用 currentRoadSegmentIndex <= 0 挡住了这个情况。
  • 使用旧版 Input.GetKeyDown 时，项目输入设置必须支持旧输入系统。本项目已调为 Both。

课堂提问

  1. 为什么真实道路有 30 段，但场景里只创建 12 个段位物体？
  2. 如果玩家在第 0 段，为什么不能后退？
  3. Time.deltaTime 为什么要乘在旋转速度上？
  4. 如果想把第 10 段改成敌人，应该改数据层还是表现层？
