圆形地图单个格子：CircleMapSegment 详解

这节课只讲一个脚本：圆圈上的一个可见格子。它不关心完整地图有多少段，也不关心玩家怎么移动。 主脚本把“这一格该显示什么”告诉它，它就负责把底图、颜色、选中放大、NPC/资源点标记显示出来。 简单说：它是一个会换皮肤、会显示小标记、会被放大的格子。

一、这个脚本在项目里负责什么？

一句话职责：显示圆圈上的一个格子。

  • 显示底下的圆点 Sprite。
  • 给圆点上色。
  • 如果这格是玩家当前所在位置，就稍微放大。
  • 如果这段路上有 NPC 或资源点，就在圆点上面叠一个内容标记。
  • 如果是空地或没有内容，就把内容标记藏起来。
重要理解：
CircleMapSegment 不是“整条路”，也不是“玩家控制器”。它只是一颗圆点。 整条路有 30 段，但屏幕上只有若干个可见圆点；每个可见圆点都挂一个这个脚本。

点击下面按钮，观察同一个格子如何切换成“普通路段 / NPC 路段 / 资源点 / 空地 / 玩家脚下”。

▶ 同一个格子，根据传入数据改变显示
普通树林道路：显示绿色圆点，无标记，不放大。

这正对应脚本里的几个方法：ShowRoadData 改底图和标记，ShowEmptyLand 显示空地并隐藏标记，SetSelected 负责放大或还原。

三、脚本执行顺序：从创建到显示

阶段发生了什么对应代码
1. Awake确认自己有 SpriteRenderer。如果 Inspector 没拖，就用 GetComponent 自动找。Awake()
2. Setup主脚本创建格子后，把 SpriteRenderer 和目标大小传进来。Setup(...)
3. 创建内容标记创建一个子物体 Content Marker，专门显示 NPC/资源点。CreateContentMarkerIfNeeded()
4. 刷新显示主脚本把某段道路数据交给它，它换图片、换颜色、设置放大、显示/隐藏标记。ShowRoadData(...)

四、动画演示②：父物体和子物体的关系

内容标记为什么要做成格子的子物体？因为子物体会跟着父物体一起移动、旋转、缩放。这样格子转到哪里，标记就跟到哪里。

▶ Content Marker 是格子的子物体，所以会跟着一起放大
Visible Segment（父物体，挂 CircleMapSegment）
SpriteRenderer：底下圆点
Content Marker（子物体：NPC/资源点标记）

代码里这句最关键：

markerObject.transform.SetParent(transform, false);

意思是：把标记物体挂到当前格子下面。以后父物体缩放，子物体也一起缩放。

五、动画演示③：sortingOrder 为什么要 +1？

底图和标记都是 SpriteRenderer。谁画在上面，由 sortingOrder 决定。数字越大，越靠前。

▶ 标记 sortingOrder 比底图大 1，所以标记盖在圆点上面
底图：5
标记：6
if (segmentSpriteRenderer != null)
{
    contentMarkerSpriteRenderer.sortingOrder = segmentSpriteRenderer.sortingOrder + 1;
}

如果不加 1，标记可能被圆点挡住，学生会以为“标记没有生成”。其实它只是画在后面看不到。

六、核心方法逐个讲

Awake()

Awake 会在物体刚创建时调用。这里用它兜底：如果 segmentSpriteRenderer 还没设置，就从同一个 GameObject 上找一个 SpriteRenderer。

if (segmentSpriteRenderer == null)
{
    segmentSpriteRenderer = GetComponent<SpriteRenderer>();
}

为什么这样做？ 因为这个脚本有 [RequireComponent(typeof(SpriteRenderer))]，Unity 会保证物体上有 SpriteRenderer；所以忘了拖引用也能正常工作。

Setup(SpriteRenderer, Vector2)

主脚本创建格子后调用它，告诉这个格子：你用哪个 SpriteRenderer 显示底图，你的目标大小是多少。

segmentSpriteRenderer = newSegmentSpriteRenderer;
targetWorldSize = newTargetWorldSize;
normalScale = Vector3.one;
selectedScale = new Vector3(1.18f, 1.18f, 1f);
CreateContentMarkerIfNeeded();

最后一行会确保内容标记子物体已经准备好。

CreateContentMarkerIfNeeded()

创建一个叫 Content Marker 的子物体。它专门负责显示 NPC 或资源点标记。

  • new GameObject("Content Marker")：创建一个新物体。
  • SetParent(transform, false)：挂到当前格子下面。
  • localPosition = Vector3.zero：和父物体中心对齐。
  • localScale = new Vector3(0.6f, 0.6f, 1f)：标记比底图小一点。
  • AddComponent<SpriteRenderer>()：给标记物体加显示图片的组件。
  • SetActive(false)：一开始先隐藏，等有内容时再显示。

ShowRoadData(...)

显示一段真实道路数据。主脚本会把“第几段、名字、图标、颜色、是不是玩家脚下、内容标记图”都传进来。

roadSegmentIndex = newRoadSegmentIndex;
roadSegmentName = newRoadSegmentName;
SetSpriteAndColor(iconSprite, segmentColor);
SetSelected(isPlayerSlot);
SetContentMarker(contentMarkerSprite);

注意它自己不决定这一段是什么类型，只负责把别人给的数据表现出来。

ShowEmptyLand(...)

显示起点后方空地。空地没有真实道路编号，所以 roadSegmentIndex = -1。同时调用 SetContentMarker(null) 隐藏标记。

SetContentMarker(Sprite markerSprite)

这个方法只管一件事：标记图为空就隐藏，不为空就显示。

if (markerSprite == null)
{
    contentMarkerSpriteRenderer.gameObject.SetActive(false);
    return;
}

contentMarkerSpriteRenderer.sprite = markerSprite;
contentMarkerSpriteRenderer.gameObject.SetActive(true);

这里的 null 可以理解成“没有图片”。没有图片时不要显示标记。

七、动画演示④：普通大小和选中放大

玩家脚下的格子会稍微放大，提示学生“玩家当前在这里”。脚本里用两个变量记大小：normalScale 和 selectedScale。

▶ 选中时从 normalScale 变成 selectedScale（1.18 倍）

这个圆点在 1.0 倍和 1.18 倍之间循环变化，模拟玩家脚下格子的放大效果。

private void SetSelected(bool isSelected)
{
    if (isSelected)
    {
        transform.localScale = selectedScale;
    }
    else
    {
        transform.localScale = normalScale;
    }
}

这里没有复杂动画，只是直接改缩放。圆环旋转时，放大的那个格子就更容易被学生看见。

八、动画演示⑤：为什么要 ResizeSpriteToTargetSize？

不同 Sprite 原始尺寸可能不一样。如果直接显示，有些格子会大、有些会小。所以换图后要按目标世界尺寸重新计算缩放。

▶ 原始图片尺寸不同，通过缩放变成统一大小

原始 Sprite：宽高不一定合适

→

目标显示大小：统一成格子尺寸

scaleX = targetWorldSize.x / spriteSize.x;
scaleY = targetWorldSize.y / spriteSize.y;
normalScale = new Vector3(scaleX, scaleY, 1f);

这就是“想要多大 ÷ 原来多大 = 要缩放多少倍”。

九、字段解释

字段作用
segmentSpriteRenderer显示底下圆点图片的 SpriteRenderer。
contentMarkerSpriteRenderer显示 NPC / 资源点标记的 SpriteRenderer。
normalScale普通状态下的大小。
selectedScale玩家脚下格子的放大大小。
roadSegmentIndex当前显示的是第几段真实道路。-1 表示起点后方空地。
roadSegmentName当前格子的显示名字，主要方便调试和课堂观察。
targetWorldSize这张图最终希望显示成多大的世界尺寸。

十、新手容易犯错的地方

  • 忘了创建内容标记子物体：如果没有调用 CreateContentMarkerIfNeeded，后面传 NPC/资源点图片也没地方显示。
  • 标记没有隐藏：空地或普通格子必须传 null，否则上一次的标记可能还留着。
  • sortingOrder 不够大：标记可能在圆点后面，看起来像没显示。
  • 把世界坐标和本地坐标搞混：内容标记是子物体，所以用 localPosition = Vector3.zero，表示相对父物体居中。
  • 换图后没重算大小：不同图片可能原始尺寸不同，不重算会导致格子大小不统一。

十一、课堂提问

Q1：为什么 CircleMapSegment 不需要知道整条路有 30 段？

因为它只负责显示“当前被分配给它的那一段”。整条路怎么滚动，是主脚本负责的。

Q2：为什么内容标记要做成子物体？

这样它会跟着格子一起移动、旋转、缩放，不需要单独算位置。

Q3：SetContentMarker(null) 表示什么？

表示这一格没有 NPC/资源点标记，所以要把标记物体隐藏。

Q4：为什么标记的 sortingOrder 要比底图大 1？

因为数字越大越靠前，标记才能盖在圆点上面。

十二、课后练习

  1. 把 selectedScale 的 1.18 改成 1.35，观察玩家脚下格子是否更明显。
  2. 把 Content Marker 的 localScale 从 0.6 改成 0.8，观察标记变大后的效果。
  3. 给怪物也做一个红色标记，并让 SetContentMarker 能显示它。
  4. 故意把 sortingOrder + 1 改成 - 1，观察标记为什么看不见，然后再改回来。
