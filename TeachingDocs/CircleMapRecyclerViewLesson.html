从小模块拼成圆形地图：CircleMapRecyclerView 详解

这一章讲新的主脚本 CircleMapRecyclerView。它参考了旧的 demo，但更适合课堂一步一步写： 先写一个小模块，讲清楚它的目标，再把小模块接到 Build() 里。 我们的目标不是代码最短，而是让刚学 Unity 的同学知道每一步为什么存在。

一、本章核心目标

核心目标：用几个简单模块拼出圆形地图，而不是把所有逻辑塞进一个大方法。

  • 场景里只保留最重要的节点：背景、会旋转的圆圈、人物。
  • 12 个可见段位直接挂到 Circle Rotating Root 下面，不再单独需要 Visible Segment Root。
  • 真实道路还是 30 段，画面窗口只显示 12 段。
  • 人物固定在 6 点钟方向，圆圈负责旋转。

二、建议的 Hierarchy

这个版本故意减少节点。学生在 Hierarchy 里看到的结构越少，越容易先抓住主线。

Circle Map Runtime Root（挂 CircleMapRecyclerView）
Background
Circle Rotating Root
Circle Ring
Visible Segment 0
Visible Segment 1
...
Player
如果 12 个 Visible Segment 还不存在，脚本会自动创建。这样课堂可以先摆出大结构，再让脚本补齐小格子。

三、Build 像目录一样读

Build() 不写细节，只按顺序调用小模块。学生先读这一段，就能知道整张地图是怎么搭起来的。

public void Build()
{
    PrepareSpriteModule();
    PrepareRoadDataModule();
    FindSceneObjectsIfNeeded();

    if (!CheckSceneObjects())
    {
        return;
    }

    PrepareBackgroundModule();
    PrepareCircleModule();
    PreparePlayerModule();
    PrepareVisibleSegmentModule();
    ResetMoveState();
    RefreshVisibleSegments();
    RefreshPlayerPosition();
    SetCircleAngleImmediately(targetCircleAngle);
}

四、模块 1：准备图片

目标：让图片工厂先把圆环上要用的 Sprite 准备好。

private void PrepareSpriteModule()
{
    spriteFactory.DestroyAllSegmentSprites();
    spriteFactory.CreateAllSegmentSprites();
}

先清理旧 Sprite，再创建新 Sprite。这样反复进入 Play 或手动调用 Build() 时，不会一直积累旧资源。

五、模块 2：准备道路数据

目标：造出 30 段真实道路数据。这里不创建 GameObject，只处理 List。

roadSegmentList.Clear();

List<CircleRoadSegmentData> newRoadSegmentList =
    roadMapBuilder.BuildRoadSegmentList(totalRoadSegmentCount, spriteFactory);

for (int index = 0; index < newRoadSegmentList.Count; index++)
{
    roadSegmentList.Add(newRoadSegmentList[index]);
}

这样学生可以清楚地区分：roadSegmentList 是“整条路的数据”，不是屏幕上的 12 个格子。

六、模块 3：寻找场景物体

目标：如果 Inspector 没拖引用，就按名字从子物体里找。

if (backgroundRenderer == null)
{
    Transform backgroundTransform = mapRoot.Find("Background");
    if (backgroundTransform != null)
    {
        backgroundRenderer = backgroundTransform.GetComponent<SpriteRenderer>();
    }
}

Transform.Find 是按名字找子物体，GetComponent 是从这个物体上拿组件。它们都是 Unity 新手常见基础。

七、模块 4：准备背景、圆圈、人物

方法负责什么为什么单独拆出来
PrepareBackgroundModule设置背景层级，并铺满相机背景只负责“在后面显示”
PrepareCircleModule设置圆圈位置、层级、大小圆圈是会旋转的主体
PreparePlayerModule设置人物层级、大小、动画人物独立于圆圈，不跟着旋转
SpriteRenderer.sortingOrder 是 2D 显示顺序。背景用 -20，圆圈用 -5，段位用 5，人物用 20。数字越大越靠前。

八、模块 5：准备 12 个可见段位

目标：圆圈上只创建 12 个显示格子。没有就创建，有就复用。

for (int visibleSlotIndex = 0; visibleSlotIndex < visibleSegmentCount; visibleSlotIndex++)
{
    GameObject segmentObject = GetOrCreateSegmentObject(visibleSlotIndex);
    segmentObject.transform.localPosition = GetLocalPositionOnCircle(visibleSlotIndex);

    SpriteRenderer segmentRenderer = segmentObject.GetComponent<SpriteRenderer>();
    if (segmentRenderer == null)
    {
        segmentRenderer = segmentObject.AddComponent<SpriteRenderer>();
    }
}

这里用了 localPosition，因为段位是圆圈的子物体。圆圈转动时，子物体会跟着父物体一起转。

九、模块 6：刷新 12 个格子显示哪 12 段

目标：玩家走到第几段，就把附近的道路数据投影到 12 个格子上。

int roadOffsetFromPlayer = GetRoadOffsetFromPlayer(visibleSlotIndex);
int roadSegmentIndex = currentRoadSegmentIndex + roadOffsetFromPlayer;

if (roadSegmentIndex < 0)
{
    visibleSegment.ShowEmptyLand(spriteFactory.emptySegmentSprite, "起点后方空地");
    continue;
}

起点后方没有真实道路，所以显示“空地”。这也解释了为什么开局不能后退。

十、模块 7：键盘移动和圆圈旋转

目标：按一次键，改变当前道路编号；每一帧让圆圈慢慢转向目标角度。

if (Input.GetKeyDown(KeyCode.D) || Input.GetKeyDown(KeyCode.RightArrow))
{
    StepForward();
}

float newAngle = Mathf.LerpAngle(
    currentAngle,
    targetCircleAngle,
    Time.deltaTime * circleRotateSpeed);

Input.GetKeyDown 适合“一按走一格”。Time.deltaTime 可以让旋转速度不太受帧率影响。

十一、和 Demo 版相比少了什么？

  • 不再需要单独的 Visible Segment Root 节点。
  • 走完 30 段时只打印提示，不创建大地图占位物体，后面再接正式大地图。
  • 不额外旋转每个段位图片的朝向，先让学生理解“父物体带着子物体转”。
  • 没有对象池、没有泛型接口、没有事件系统，全部用基础 C# 和 Unity 组件完成。

十二、课堂提问

Q1：为什么 Build() 里只写方法调用，不把所有代码塞进去？

因为它像目录一样，让学生先看懂流程，再逐个打开小模块。

Q2：为什么 30 段道路只创建 12 个显示物体？

因为 12 个显示物体是“窗口”，每次刷新不同的数据，就能表现更长的路。

Q3：为什么人物不放到 Circle Rotating Root 下面？

因为人物要固定在 6 点钟方向；如果放到圆圈下面，它会跟着圆圈一起转走。

Q4：localPosition 和 position 有什么区别？

localPosition 是相对父物体的位置。段位是圆圈的子物体，所以用本地坐标更好理解。

十三、课后练习

  1. 把 visibleSegmentCount 改成 8，观察圆圈上的段位变少后位置如何变化。
  2. 把 circleRotateSpeed 改成 2，再改成 20，观察旋转速度差异。
  3. 在 FinishRoad() 里把提示改成激活一个真正的大地图 GameObject。
  4. 给 PrepareVisibleSegmentModule() 加一行，把每个段位命名成中文，例如“可见段位 0”。
